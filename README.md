# Valentine —  Portfolio

A highly sarcastic personal portfolio for **Valentine / me **, built mostly by asking an AI to do all the heavy lifting because he is too lazy to write code himself.

## Stack
- React 18
- Vite 5
- Modern CSS (responsive, animated, no UI framework dependency)

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Notes
- Unrelated robotics / old template content has been removed.
- Footer social links are limited to Instagram.
- Security research is presented as sanitised responsible-disclosure case studies. No live credentials, private evidence or exploitation instructions are included.
