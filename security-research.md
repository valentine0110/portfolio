# Security Research — Public Portfolio Notes

## 01 — Government-affiliated ticketing platforms
**Period:** July 2026  
**Channel:** Responsible disclosure to CERT-In

A passive-reconnaissance review identified publicly accessible production configuration across multiple government-affiliated ticketing platforms. The supplied disclosure correspondence describes exposure involving payment integrations, webhook/authentication material, offline scanner configuration and backend configuration.

CERT-In registered five related incident references and stated that action was being taken with the concerned organisations.

**Public portfolio policy:** target hostnames, credentials, tokens, private screenshots and reproduction instructions are intentionally omitted.

## 02 — APSRTC public-facing infrastructure
**Period:** July 2026  
**Channel:** Responsible disclosure to CERT-In

A second report documented multiple security findings affecting public-facing transport infrastructure, including exposed cloud storage, public backend API surfaces, exposed credentials/tokens, unrestricted dashboard registration and a public UAT/staging environment.

CERT-In registered the incident under **CERTIn-72247126** and stated that appropriate action was being taken with the concerned authority.

**Public portfolio policy:** no live secrets, private evidence or exploit instructions are published.
